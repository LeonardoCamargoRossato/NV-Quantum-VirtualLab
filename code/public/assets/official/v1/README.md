# Fotografia oficial — recortes V1 aprimorados

Fonte original preservada: `code/public/assets/official/DeviceV1.png`.
Crédito: Quantum Village / Uncut Gem, licença AGPL-3.0, conforme `code/public/assets/licenses/UncutGemLicense.txt`.

Os 11 PNGs são gerados por `code/scripts/enhance_uncut_gem_v1.py`, apenas com recortes matemáticos,
interpolação LANCZOS 2×, aumento leve de contraste e máscara moderada de nitidez. **Sem IA generativa.**
A melhora na visualização não recupera caracteres ou características não visíveis na fotografia-fonte.
Os 4 recortes extras são *regiões descritivas*, não identificações definitivas de componentes.

A interface usa o original na área de montagem interativa (hotspots preservados), e as imagens
aprimoradas nos painéis de inspeção, miniaturas, zoom e galeria de detalhes.
O arquivo `manifest.json` será gerado com retângulos, dimensões e hash da fonte.
